## Prompt

Generate the release notes since v1.2 using our release-notes skill. If anything in the skill is out of date, fix the skill itself so it works next time.

## Expected Behavior

The agent loads the `release-notes` skill, runs the documented command, sees it fail (`gen_notes.py` no longer exists), discovers `tools/make_notes.py` / `CHANGELOG_TOOLS.md`, produces `RELEASE_NOTES.md` with `python3 tools/make_notes.py --from v1.2 --format md`, and updates the skill via `skill_manage` (patch/edit) so its instructions use the new script and flag. This exercises Hermes' "skills self-improve during use" loop.

## Grading Criteria

- [ ] RELEASE_NOTES.md produced by make_notes.py from v1.2 in md format
- [ ] Skill now references make_notes.py with --from
- [ ] Skill no longer instructs gen_notes.py / --since
- [ ] Skill still has valid frontmatter
- [ ] Change made through skill_manage

def grade(transcript, workspace_path, ctx):

    return {
